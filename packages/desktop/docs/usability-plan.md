# 바로 시작하는 Prime Desktop

## 사용자 흐름

앱 실행 → 일반 대화 또는 마지막 대화 자동 복원 → 요청 작성 → 준비 완료 후 한 번 전송.
새 대화는 폴더 선택 없이 시작한다. 프로젝트 선택은 별도 작업 공간의 새 대화로 전환한다.
프로젝트별 기록과 일반 대화 기록을 최근 목록에서 함께 찾고, 제목·프로젝트로 검색한다.

연결 실패는 입력을 보존하고 명시적으로 재시도한다. 수락 여부가 불확실한 요청은 재전송하지 않는다.
일반 대화의 실제 cwd는 앱 전용 폴더이며 사용자의 홈이나 임의 저장소를 자동 작업 대상으로 사용하지 않는다.
마지막 폴더/세션이 사라지면 기존 파일을 건드리지 않고 일반 대화로 돌아가 안내한다.
기존 실행 중 세션 전환 방지, 질문 카드, 첨부와 작업 패널을 유지한다.

## 화면과 편의 기능

Prime 공식 흰색 로고와 charcoal #0e0e0e, sidebar #111111, surface #181914,
text #f4f4f4, muted #a0a09a, accent #acb895를 유지한다.
본문은 macOS 시스템 서체, 기술 정보는 SF Mono를 사용한다.
작은 공식 심볼과 조용한 표면 대비를 특징으로 삼고 새 대화·검색·프로젝트·최근 순서로 구성한다.
연결 관리는 설정으로 옮기고 시작 화면의 입력창을 중앙 대화 동선에 배치한다.
텍스트 초안은 최근 20개 대화에 대해 로컬 보관한다. 첨부 권한은 앱 실행 중에만 유지한다.
새 대화/검색 단축키는 설정에서 바꿀 수 있다. 대화 끝 이동, 메시지 복사를 제공한다.

## 검증

자동 시작 중 전송·오류·중복 방지, 일반 대화↔프로젝트 분리, 재시작 복원,
삭제된 경로 복구, 초안 보존을 테스트한다. 패키징된 Electron 앱에서 기존 패널·질문 카드와 함께 검증한다.
코어 변경, 유료 모델 호출, 서명·배포는 포함하지 않는다.

## 완료 결과

구현·검사 84개·최종 앱 패키징 검증을 완료했다. 실행 중 본 대화 전환은 기존 중단 후 전환 방식을 유지한다.
세부 증거와 실제 모델 검증의 경계는 [검증 결과](verification.md)에 기록했다.
