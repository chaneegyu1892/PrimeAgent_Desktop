# 확장 기능 완성 계획

2026-09-08. 기존 자동 연결·대화·개입·작업 패널 구현 위에 진행한다.

1. 공식 Prime Agent Skills/패키지 계약과 MCP SDK를 확인한다. 공식 제공 기능과 앱에서 추가할 기능을 구분한다.
2. 앱 전용 라이브러리를 만든다. 기본 Skills, 로컬 Skill/Prime 패키지 가져오기, 활성화/비활성화/제거, 내용 확인을 제공한다.
3. MCP 연결을 앱에서 관리한다. stdio/Streamable HTTP, 환경변수 참조/암호화 토큰, 실제 연결 검사와 도구 탐색, 에이전트 호출, 연결 해제를 구현한다. Aside는 설치를 탐지해 기본 연결한다.
4. 코딩, 디버깅, 리뷰, 브라우저, 조사, 문서, PDF, 표, 슬라이드, 데이터 분석, 디자인, 업무 커뮤니케이션, 통합 작업의 기본 Skills를 제공한다. 실행 가능한 아티팩트 도구와 구체적 검증 절차를 함께 제공한다.
5. 진행 중 작업을 중단하지 않고 변경을 저장하고, Skill/플러그인 변경은 사용자가 대화 보존 재연결로 반영한다. MCP 변경은 다음 도구 호출부터 반영한다.
6. 타입/경계/영속화/MCP 실제 핸드셰이크·호출·종료, 패키징된 외부 CLI 확장 로더, 실제 Electron 화면을 검증한다.

계정이 필요한 서비스는 연결 전 상태를 표시한다. 외부 서비스 전체를 무조건 설치하거나 로그인된 것처럼 표시하지 않는다. 기존 Prime/Codex 전역 설정과 인증 파일을 변경하지 않는다. 발송/결제/배포 등 외부 효과는 원래 사용자 요청의 권한 범위에서 수행한다.

## 완료와 검증

위 여섯 단계의 데스크톱 구현을 완료했다. 기본 Skills 15개, 문서 실행 도구, 로컬 Skill/플러그인 관리, MCP HTTP/stdio와 OAuth/토큰 관리, Aside 자동 탐지, 14개 서비스 연결 템플릿을 제공한다. 최종 앱과 외부 Prime 로더에서 실제 읽기/등록을 확인했다. 자세한 증거는 [검증 결과](verification.md)에 기록했다.

계정 인증은 사용자 소유이므로 서비스별 로그인·API 활성화가 필요한 항목을 연결된 것처럼 표시하지 않는다. 자동 업데이트/서명·공용 작업의 detach/attach·subagent 전용 상세 화면 등 기존 문서에 명시한 후속 범위는 그대로 남아 있다. 이는 모든 Codex 기능 동등성 선언이 아니다.
