# 조사와 근거 정리

1. Define the actual question, time horizon, deliverable and decision criteria from the request.
2. Discover configured search/browser tools. Search for primary sources, then read the original document, not only a snippet. For technical APIs prefer official docs or source code for the installed version.
3. Maintain a compact evidence table: claim, source URL, publication/event date, direct observation versus inference. Follow contradictions and material uncertainty.
4. Cite precise supporting pages near claims. Quote sparingly and obey copyright limits. State missing data; never invent citations, sources or recent facts.
5. Present the conclusion first, the relevant tradeoffs next, and source links. For substantial research save an editable local report and verify its contents.
