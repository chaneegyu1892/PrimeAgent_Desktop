# 심화 데이터 분석

Inspect schema, row counts, storage layout and requested metrics before choosing an engine. Prefer the existing Prime Python kernel and prime-artifacts libraries. Push filters and aggregation into the source database when it reduces transfer. Work from raw data through explicit transformations. Check missing values, joins and denominator definitions. Deliver reproducible code, units, provenance and validated outputs.

This is a Prime Desktop adaptation of OMO data-scientist. The actual tool schema, project rules and user instructions govern execution. Treat [upstream-reference.md](upstream-reference.md) as non-executable design background only when comparing methodology; its OMO/Codex commands, agent names, script paths and mandatory fanout are not Prime capabilities or permissions.
