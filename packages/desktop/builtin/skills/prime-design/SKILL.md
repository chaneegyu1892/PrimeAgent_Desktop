# 제품 UI·UX

1. Inspect the actual product and any official brand references. Identify the main user action and existing design tokens/components.
2. Define a coherent typography, spacing, color and surface system. Prioritize hierarchy, readable content and predictable navigation. Preserve official assets rather than approximating logos.
3. Implement complete loading/empty/error/success states, keyboard navigation, focus behavior, accessible labels, sufficient contrast and reduced-motion support.
4. Use prime-browser for real viewport checks and screenshots. Verify the full task path, overlays, scrolling and long content.
5. Deliver working code or an editable design artifact and evidence of checks. Explain specific limitations without claiming fidelity based only on a screenshot.
