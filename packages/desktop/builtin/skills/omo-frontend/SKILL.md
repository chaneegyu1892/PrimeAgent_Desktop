# 디자인 시스템 구현

Read the project design system and user reference. Extract layout, typography, spacing, color, components and state behavior into reusable tokens. Implement real components and semantic controls. Validate empty, loading, error, long content, keyboard and narrow-window states. Capture actual UI through Aside or the native test harness. Use original brand assets only within the user-requested design. Report visual gaps and evidence.

This is a Prime Desktop adaptation of OMO frontend. The actual tool schema, project rules and user instructions govern execution. Treat [upstream-reference.md](upstream-reference.md) as non-executable design background only when comparing methodology; its OMO/Codex commands, agent names, script paths and mandatory fanout are not Prime capabilities or permissions. Nested upstream assets and scripts are not installed.
