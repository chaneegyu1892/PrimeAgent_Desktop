# 프로젝트 지도

Read existing root and nested instructions, manifests and directory structure. Use bounded explore tasks only for independent modules. Return an evidence-backed module map and dependency boundaries. Write AGENTS files only if the user requested agent instructions; otherwise deliver a map under the existing docs convention. Keep project facts local to the module that owns them and avoid duplicate guidance.

This is a Prime Desktop adaptation of OMO init-deep. The actual tool schema, project rules and user instructions govern execution. Treat [upstream-reference.md](upstream-reference.md) as non-executable design background only when comparing methodology; its OMO/Codex commands, agent names, script paths and mandatory fanout are not Prime capabilities or permissions. Nested upstream assets and scripts are not installed.
