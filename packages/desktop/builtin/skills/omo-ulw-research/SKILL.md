# 병렬 근거 조사

Decompose the question into distinct evidence needs. Delegate bounded research tasks only where useful, each with an explicit source and output requirement. Keep the critical path local. Read primary sources, record exact version or commit, and distinguish current facts from inference. Synthesize all findings with contradictions and unavailable evidence. Save one report in the project docs convention.
