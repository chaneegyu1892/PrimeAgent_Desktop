# 프레젠테이션

1. Establish audience, purpose, aspect ratio and source material. Inspect any supplied deck/template before editing.
2. Load prime-artifacts and use python-pptx. Build a slide narrative with one main message per slide, consistent margins, hierarchy and restrained colors. Use editable text, charts and shapes where possible.
3. Verify facts and chart data. Source real visual assets; avoid invented logos or claiming generated imagery is official.
4. Reopen the PPTX, check slide count and text, shapes within slide bounds and font sizes. Render with an available office tool and inspect every slide for clipping/overlap; report when rendering was unavailable.
5. Deliver the editable deck plus verified previews and source/assumption notes.
