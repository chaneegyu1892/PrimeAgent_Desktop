# Git 변경 관리

Inspect status, branch, remotes and repository rules. Identify owned paths and unrelated changes. For a requested commit, review the exact staged diff and include only explicit paths. Use existing tests and verification evidence. For history repair explain the affected commits and safe sequence first. Follow the user and repository authorization for push, merge and destructive history operations; this skill grants no extra permission.
