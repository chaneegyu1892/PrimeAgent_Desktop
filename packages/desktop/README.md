# Prime Desktop

macOS Apple Silicon용 개인용 Prime Agent 데스크톱 클라이언트입니다. Electron은
화면과 로컬 앱 상태를 담당하고, 작업 실행은 **별도 설치된 Prime Agent CLI**가
담당합니다. 기존 에이전트 코어는 수정하지 않았습니다.

## 실행

기존 설치는 왼쪽 하단 **앱 업데이트 → 업데이트 확인 → 업데이트 다운로드 → 재시작하여 설치**로 갱신합니다.
업데이트는 현재 앱의 경로를 그대로 교체하므로 Dock에 고정한 아이콘을 다시 등록할 필요가 없습니다.
신규 설치 파일은 [데스크톱 릴리스](https://github.com/chaneegyu1892/PrimeAgent_Desktop/releases)에서 받습니다.

개발 환경의 기본 빌드 경로:

```text
packages/desktop/out/Prime Desktop-darwin-arm64/Prime Desktop.app
```

Finder에서 앱을 열거나 저장소 루트에서 실행합니다.

```sh
open "packages/desktop/out/Prime Desktop-darwin-arm64/Prime Desktop.app"
```

1. 앱을 열면 자동으로 준비하고 마지막 대화를 복원합니다. 처음 실행하면 **일반 대화**로 시작합니다.
2. 프로젝트 없이 바로 질문할 수 있습니다. 폴더 작업이 필요할 때 **폴더 열기**를 선택합니다.
3. 요청을 입력하고 **Enter** 또는 화살표 전송 버튼을 누릅니다. **Shift+Enter**는 줄바꿈입니다.
4. 실행 중 기본 전송은 자동으로 **추가 지시**가 됩니다. 현재 작업 다음에 처리하려면 **후속 작업**을 선택합니다.
5. **중단**으로 현재 작업을 멈춥니다. **진단 로그**에서 오류를 확인하고 복사할 수 있습니다.

입력창은 기본 한 줄에서 내용에 맞춰 최대 8줄까지 자동으로 늘어나며, 더 긴 내용은
입력창 안에서 스크롤합니다. 전송하거나 내용을 지우면 다시 줄어듭니다. 한글 조합을
확정하는 Enter는 전송하지 않습니다. **설정 → 메시지 입력 → 전송 단축키**에서
⌘/Ctrl+Enter 방식으로 변경할 수 있고, 이 설정은 재실행 후에도 유지됩니다.

사이드바의 **프로젝트**에는 폴더 아이콘 아래 해당 프로젝트의 저장된 세션이 표시됩니다.
화살표로 폴더를 접고 펼치고, 폴더 옆 **+**로 새 세션을 시작합니다. **최근**에는 등록한
프로젝트 세션과 일반 대화가 마지막 대화 시간순으로 표시됩니다. 세션을 누르면 해당 작업 공간으로 이동해
자동으로 연결하고 대화를 복원합니다. 실행 중에는 먼저 중단한 뒤 세션을 이동하세요.
세션 이름은 설정에서 변경할 수 있으며, 이름이 없으면 첫 사용자 요청을 표시합니다.

입력창의 **클립 아이콘**으로 파일을 첨부하고 **×**로 제거합니다. PNG/JPEG/WEBP/GIF는
이미지 데이터로 전달하고, 문서·코드 등 다른 파일은 로컬 경로를 메시지에 넣어 에이전트가
읽도록 합니다. 파일당 이미지 8MB, 이미지 합계 20MB, 한 메시지 10개까지 지원합니다.
이미지 해석은 선택한 모델의 이미지 지원 여부에 따라 달라집니다. 문서 형식의 실제
해석은 CLI가 사용할 수 있는 도구에 따릅니다. 파일을 이동·삭제하면 다시 선택하세요.
첨부만 있어도 전송할 수 있고, 실패하면 첨부와 입력을 유지합니다. 텍스트 초안은 최근 20개 대화까지 이 기기에 보관하고 재실행 후 복원합니다.
첨부 선택은 앱 실행 중에만 유지하므로 재실행 후 파일을 다시 첨부하세요.

왼쪽 프로젝트 목록과 오른쪽 실행 내역은 상단 버튼으로 접거나 펼칠 수 있습니다.
실행 내역은 기본적으로 접혀 있으며, 모델 이름을 누르면 설정 화면이 열립니다.

인증 오류가 나면 터미널에서 기존 `prime-agent`를 실행하고 `/login`으로 로그인한
뒤 앱에서 다시 연결하세요. 모델 인증은 기존 CLI가 관리합니다. 외부 MCP 서비스의 토큰과 OAuth는 확장 라이브러리에서 별도로 설정합니다.

## 무료 앱 업데이트

앱은 새 데스크톱 릴리스를 자동으로 확인하고 왼쪽 하단에 알림을 표시합니다.
알림에서 **업데이트 다운로드**를 선택하고, 작업을 마친 뒤 **재시작하여 설치**를 누릅니다.
일반 종료나 알림 수신만으로 설치하지 않습니다. 진행 중인 작업·답변 대기·열린 터미널·미전송 첨부가 있으면
설치를 막습니다. 배포 키 서명과 파일 무결성을 검증하고, 교체 전 앱을 백업합니다.
Apple Developer 유료 계정은 필요하지 않습니다. 최초 실행에는 macOS의 확인이 필요할 수 있습니다.
업데이트는 소스 커밋이 아니라 포크 저장소에 게시된 데스크톱 릴리스를 기준으로 합니다.

[배포·키 백업·업데이트 복구 안내](docs/updates.md).

## 확장 라이브러리

사이드바 **확장 라이브러리**에서 관리합니다.

- **Skills**: 기존 15개와 OMO에서 Prime에 맞춰 이식한 17개, 총 32개를 기본 제공합니다. 코딩·진단·리뷰·조사·디자인·문서·데이터·계획 실행을 다루며 내용 보기, 검색, 켜기/끄기, `/skill:name` 입력을 지원합니다.
- **문서 실행 도구**: python-docx, openpyxl, python-pptx, pypdf, reportlab, pandas, matplotlib, Pillow를 고정 버전으로 선언한 Python-backed Skill입니다. 첫 Prime 커널 준비에서 의존성을 설치하므로 인터넷 연결과 준비 시간이 필요합니다. 사용자 지정 Python 환경에는 직접 설치해야 합니다. `prime_artifacts.status()`와 `inspect_file()`로 준비 상태와 산출물 구조를 확인합니다.
- **MCP 연결**: HTTP/stdio 추가·수정·삭제·활성화, 실제 연결 검사와 도구 스키마 확인을 제공합니다. 토큰은 OS safeStorage로 암호화하며 환경변수 참조도 지원합니다. OAuth/DCR·PKCE 로그인과 로그아웃을 지원하며 자동 로그인 창은 에이전트 호출에서 열리지 않습니다.
- **Aside**: 설치된 CLI를 자동 탐지해 기본 MCP로 등록합니다. 패널의 브라우저 읽기와 별개로 에이전트가 `desktop_mcp`를 통해 실제 도구를 탐색·호출할 수 있습니다. 이미지 결과는 모델용 이미지 블록으로 전달합니다.
- **서비스 둘러보기**: GitHub, Context7, grep.app, Notion, Linear, Figma, Supabase, Vercel, Google Workspace 등 15개 연결 템플릿을 제공합니다. Context7·grep.app은 최초 한 번 기본 등록하며 실제 사용 시 연결합니다. 기존 수정·삭제 설정은 존중합니다. 템플릿이 로그인이나 서비스 사용 권한을 의미하지 않습니다. Google은 사전 OAuth 등록/API 활성화 후 발급한 액세스 토큰이 필요하고, Figma에는 클라이언트 승인 조건이 적용될 수 있습니다.
- **플러그인**: 명시적인 `pi.skills`/`pi.extensions`가 있는 로컬 Prime 패키지를 복사해 관리합니다. 가져온 Skill/플러그인은 기본 꺼짐입니다. 패키지 내용·실행 확장을 검토한 뒤 켭니다. 확장은 의존성까지 번들한 JS/MJS/TS 파일을 사용하세요. 가져오기는 npm 스크립트를 실행하지 않으며 glob, 심볼릭 링크, 외부 경로와 20MB 초과 패키지는 거절합니다.

Skills·플러그인 변경 후 **지금 적용**은 현재 본 대화를 보존하며 재연결합니다. 실행 중에는 작업을 마친 뒤 적용할 수 있습니다. 사이드 채팅은 자체 재연결 때 반영합니다. MCP 변경은 다음 호출에 반영하며 기존 연결을 닫습니다. 제거한 로컬 파일은 실행 중 참조 보호를 위해 다음 앱 시작 때 정리합니다.

설정은 userData의 `capabilities/capabilities.json`, 복사한 패키지는 `capabilities/installed`에 보관합니다. Prime/Codex 전역 설정·인증 파일은 변경하지 않습니다. 공식 SDK 1.30.0의 Streamable HTTP/stdio 범위를 지원하며 모든 MCP 버전·서버, 모든 Codex 기능과 동일하다고 보장하지 않습니다.

[공식 자료 조사와 공급자별 조건](docs/capability-research.md), [구현 계획](docs/capability-plan.md).

## 바로 시작하는 대화

- **새 대화**는 프로젝트와 무관한 일반 대화를 시작합니다. 기본 단축키는 ⌘N입니다.
- **대화 검색**은 제목과 프로젝트 이름으로 기록을 찾습니다. ⌘K로 검색창에 이동합니다.
- 단축키는 설정에서 변경할 수 있습니다. 작업 패널 단축키와 겹치면 저장하지 않습니다.
- 일반 대화는 앱 전용 작업 폴더를 사용하며 프로젝트 목록에 폴더로 표시하지 않습니다.
- 앱 시작 중에도 작성하고 전송할 수 있습니다. 준비 후 한 번만 전달하며, 중단하면 대기 중 전송을 취소합니다.
- 오류 시 초안을 유지합니다. 불확실한 전송은 자동 재전송하지 않습니다.
- 마지막 폴더나 기록이 사라졌다면 일반 대화에서 복구 안내를 표시합니다. 세션 복원이 거절된 경우에는 전송을 막고 사용자의 재연결 또는 새 대화 선택을 기다립니다.
- 메시지의 **복사**, 스크롤 중 **최근 메시지로 이동**, 설정 진입 시 모델 목록 자동 불러오기를 지원합니다.
- 연결 관리는 설정 안에 있습니다. 실행 중 세션 전환은 현재 작업을 중단한 뒤 가능합니다.

## 작업 중 질문과 개입

에이전트가 사용자 판단을 필요로 하면 대화 안에 **선택·확인·입력·편집 카드**가 나타납니다.
앱에 포함된 `desktop_ask_user` 도구를 본 대화와 사이드 채팅의 CLI에 기본 연결하므로,
별도 확장 설치 없이 에이전트가 질문 카드를 요청할 수 있습니다. 선택형 질문에는
**직접 입력**도 제공하며, 선택이나 초안을 자동으로 제출하지 않습니다.

- 질문에 답하면 해당 요청을 기다리던 작업이 계속됩니다. 거절·취소는 승인으로 처리하지 않습니다.
- 실행 중 입력창에서 방향을 보완하거나, 후속 작업을 예약하거나, **중단**할 수 있습니다.
- 숨겨진 사이드 채팅에 질문이 오면 상단 알림에서 해당 대화의 질문을 열어 답할 수 있습니다.
- 답변 대기 중에는 일반 RPC 시간 제한을 멈춥니다. 질문 자체에 지정된 제한 시간이 있으면 표시하고 만료시킵니다.
- 중단·연결 종료 시 이전 질문은 닫힙니다. 연결 오류의 **다시 연결**은 저장된 현재 세션을 복원하며 요청을 자동 재전송하지 않습니다.
- 진행 알림·상태·텍스트 위젯도 표시합니다. 에이전트가 제안한 입력은 사용자가 적용하며 기존 초안을 유지합니다.

질문 카드는 에이전트가 이 도구 또는 기존 확장의 UI 요청을 사용할 때 표시됩니다.
일반 텍스트로 물어본 질문은 입력창에서 답하면 됩니다. 모든 도구 실행에 일괄 승인을
강제하는 기능은 아니며, 확인 요청은 해당 작업의 구체적인 범위에만 적용됩니다.
현재 CLI는 확인 질문의 취소와 거절을 모델에 모두 `false`로 반환하므로, 도구는 이를
`not_approved`로 전달합니다. 앱에서는 둘을 구분해 표시합니다.

## 작업 패널과 Aside

상단 오른쪽 **작업 패널** 아이콘으로 접고 펼칩니다. 패널 상단에서 확대·복원하거나
오른쪽과 아래쪽 배치를 바꿀 수 있습니다. 초기 화면은 여섯 도구를 보여줍니다.

| 도구 | 기능 | 기본 단축키 |
| --- | --- | --- |
| 검토 | 프로젝트의 Git 변경 목록, 스테이징/작업 디렉터리 diff | Ctrl+Shift+G |
| 터미널 | 프로젝트 폴더에서 실행하는 실제 zsh 터미널 | Ctrl+` |
| 브라우저 | Aside 탭 목록·페이지 내용 읽기·새 주소 열기 | ⌘T |
| 파일 | 폴더 탐색, 이름 필터, 텍스트·이미지 미리보기 | ⌘P |
| 사이드 채팅 | 본 대화와 분리된 Prime 세션, 전송·중단·새 대화 | ⌥⌘S |
| 에이전트 작업 | 역할별 작업, 선행 의존성, 진행·질문·중단·재개, 프로젝트 기억 | ⇧⌘J |

패널 초기 화면의 **단축키 설정**에서 변경할 수 있고 재실행 후에도 유지됩니다.
파일·페이지의 **대화에 넣기**와 **검토 요청 작성**은 본 대화 입력창에 참고 내용을
넣습니다. 실제 전송은 사용자가 합니다. 파일 화면은 미리보기이며 파일 편집이나
Git 스테이징·커밋 버튼은 제공하지 않습니다.

Aside는 실행 중인 **외부 Aside 창**과 CLI로 연결합니다. 열린 탭 목록을 새로고침하고
탭을 선택해 페이지 텍스트를 읽거나 HTTP(S) 주소를 열 수 있습니다. 앱 내부에 웹페이지를
임베드하지 않습니다. 이 연결은 Prime Agent의 전역 MCP 설정을 변경하지 않습니다.
Aside CLI는 `~/.local/bin/aside`, `/opt/homebrew/bin/aside`, `/usr/local/bin/aside`에서
찾습니다. 연결 오류가 표시되면 Aside 실행·로그인 및 앱 내 CLI 설치를 확인하세요.

터미널은 패널을 접거나 다른 도구로 이동해도 유지되며, **터미널 종료** 또는 앱 종료 시
닫힙니다. 터미널과 사이드 채팅은 각각 최대 8개 프로젝트를 동시에 지원합니다.
사이드 채팅은 같은 프로젝트에서 별도의 CLI 세션을 사용하며, 본 대화는 **본 대화 참고**를
눌러 명시적으로 전달할 수 있습니다. CLI와 터미널은 사용자 권한으로 실행됩니다.
사이드 채팅 기록은 Prime 세션으로 저장되지만, 앱 재시작 후 패널에 자동 복원하지 않습니다.

## OMO에서 도입한 작업 기능

**작업 패널 → 에이전트 작업**에서 요청과 완료 기준을 등록합니다. 본 대화에서도 에이전트가
`desktop_tasks`로 작업을 분담할 수 있습니다. 역할별 모델, 동시 실행 수, 미완료 작업 수,
응답 실행 시간 한도는 **실행 설정**에서 변경합니다. 질문에는 패널의 카드로 답하고,
추가 지시·하위 작업 포함 중단·명시적 재개·대화에서 결과 검토를 지원합니다.

같은 프로젝트의 백그라운드 작업은 순차 실행하며 다른 프로젝트는 기본 2개까지 병렬 실행합니다.
작업 패널을 닫아도 실행되지만 앱 종료 시에는 멈춥니다. 재시작하면 작업 기록을 복원하고
대기열을 일시정지합니다. 실제 모델 사용료는 기존 공급자 기준입니다.

`desktop_code`는 줄 해시와 파일 digest를 검사하는 편집, `desktop_ast`는 코드 구조 검색,
`desktop_lsp`는 TS/JS 정의·참조·진단·이름 변경 미리보기, `desktop_memory`는 프로젝트별
근거 있는 기억 검색·저장·삭제를 제공합니다. 기억은 패널에서 직접 확인·편집·삭제할 수 있습니다.

[도입 범위와 사용법](docs/omo-adoption.md), [원본 기능 전수 조사](docs/omo-adoption-research.md).

## CLI 경로

PATH, `~/.local/bin`, Homebrew 경로, `~/.nvm/versions/node/*/bin`을 탐색합니다.
찾지 못하면 **설정 → 파일 선택**으로 실행 파일을 선택하세요. Node CLI는 해당
실행 파일 옆의 외부 Node를 우선 사용하므로 Finder에서 시작해도 nvm CLI를 실행할
수 있습니다. Electron 자체를 Node CLI 실행기로 사용하지 않습니다.

이 작업 환경에서 확인한 설치: `prime-agent 0.9.3`

```text
/Users/jinkyu/.nvm/versions/node/v24.19.0/bin/prime-agent
```

이 경로는 코드에 하드코딩하지 않았습니다. 앱에는 Prime Agent나 Python runtime이
포함되지 않으므로 기존 CLI 설치와 그 실행 환경이 필요합니다.

## 개발·설치·검사·패키징

Node **22.12 이상**과 npm **11.10 이상**이 필요합니다. 검증 환경은 Node 24.19.0 /
npm 11.17.0입니다. 루트의 에이전트 build/dev/test 명령은 실행하지 않습니다.
모든 명령은 아래 desktop 디렉터리에서 실행합니다.

```sh
cd /Users/jinkyu/PrimeAgent_App/packages/desktop

# desktop만 설치: 루트 workspace 의존성·설치 스크립트에 영향을 주지 않습니다.
npm ci --workspaces=false --ignore-scripts
node node_modules/electron/install.js

npm run dev                 # 로컬 빌드 후 Electron 실행; 변경 시 다시 실행
npm run check               # Biome + TypeScript
npm test                    # 로컬 MCP 서버 포함, 유료 API를 사용하지 않는 테스트
npm run build
npm run package             # unsigned/ad-hoc arm64 .app 생성
npm run test:smoke          # 개발 Electron + offline fixture
npm run test:smoke -- --packaged
```

새 의존성 추가·업데이트 시 `--min-release-age=7`을 사용합니다. 의존성은 desktop의
package-lock.json에 고정했습니다. npm workspace 패키지로 인식되며, 저장소 루트의
기존 wildcard workspace 설정을 그대로 사용합니다.

패키징은 `@electron/packager`로 수행합니다. 빌드된 JS/CSS/HTML과 필요한 node-pty 런타임을
포함하고, 네이티브 PTY 바이너리·실행 도우미와 외부 CLI용 질문/MCP 도구·기본 Skills는 ASAR 밖에 둡니다. 개발 소스, 테스트,
불필요한 의존성, 개인 설정, 인증 파일은 앱에 포함하지 않습니다.

## 권한과 알려진 제한

- Renderer는 sandbox로 격리하지만 macOS App Sandbox는 적용하지 않습니다.
  에이전트는 현재 사용자 권한으로 실행됩니다. 선택한 폴더는 cwd이며, 에이전트의
  파일 접근을 강제로 제한하는 보안 경계는 아닙니다.
- 무료 배포 키 기반 업데이트를 지원하며, Apple notarization·App Store 배포는 포함하지 않습니다.
  unsigned/ad-hoc 앱 교체 후 macOS 권한을 다시 요청받을 수 있습니다.
- Full Disk Access를 기본으로 요구하지 않습니다. 보호된 폴더에서 실제 접근 오류가
  발생한 경우에만 macOS 권한을 확인하세요. SIP나 운영체제 보호를 우회하지 않습니다.
- 앱 창을 닫으면 앱도 종료되고 일반 RPC 작업도 종료됩니다. 공용 daemon을 강제로
  종료하지 않습니다. 작업을 유지한 채 detach/attach하는 UI는 후속 범위입니다.
- 앱 재실행 시 마지막 대화를 자동 복원합니다. 사이드바에서 다른 저장된 세션으로
  이동할 수 있습니다. 별도 JSONL 파일은 작업 공간 준비 후
  **세션 열기**로 가져오면 목록에도 등록됩니다.
- 백그라운드 작업·서브에이전트 상세 관리는 작업 패널에서 제공합니다. 같은 프로젝트의
  본 대화·사이드 채팅과 파일을 공유하므로 격리된 worktree 실행은 아닙니다. 작업 기록은 최대 500개,
  프로젝트 기억은 최대 200개입니다. compaction 버튼과 앱 종료 후 상주 실행은 포함하지 않습니다.
- 확장 기능의 `select/confirm/input/editor`를 지원합니다. TUI 전용 custom UI는
  기존 TUI를 사용하세요. 질문 이력과 미응답 카드는 앱 재시작 후 복원하지 않습니다.
  답변은 Markdown 서식으로 표시하고,
  사용자 입력과 도구 출력은 원문으로 표시합니다. 링크는 텍스트로만 표시하며 외부
  이미지를 자동으로 불러오지 않습니다.
- 화면에는 최근 메시지 1,000개·실행 내역 100개·진단 200개를 표시합니다. 원본 세션
  기록은 Prime이 관리합니다. 알려진 비밀 패턴을 마스킹하나 모든 임의 문자열을
  비밀로 판별할 수는 없습니다.
- 대화 자동 테스트는 가짜 CLI/transport를 사용하고 질문 도구는 설치된 CLI의 실제 로더로도 확인했습니다. 실제 모델 응답, 파일 수정,
  Python 도구 실행의 최종 확인은 사용자 환경에서 직접 해야 합니다.

설정 파일은 Electron userData 아래 `desktop-settings.json`입니다. 손상된 파일을
발견하면 기존 파일을 덮어쓰지 않습니다. 앱을 종료하고 해당 파일을 별도 보관한 뒤
다시 시작하면 기본 설정으로 복구할 수 있습니다.
